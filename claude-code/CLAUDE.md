# Commits & PRs

- No Claude/Anthropic attribution anywhere in a commit or PR — no `Co-Authored-By: Claude` trailer, no "Generated with Claude Code" line, no signature of any kind. End the commit message after the body.
- Check the repo for its own commit/PR conventions first (CONTRIBUTING.md, a repo-level CLAUDE.md/AGENTS.md, a PR template) and follow those over anything below.
- Absent repo-specific conventions, use the caveman-commit skill for commit messages and the pull-request-description skill for PR titles and bodies.
